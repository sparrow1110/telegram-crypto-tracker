# Crypto Monitoring Telegram Bot

Это телеграм-бот для мониторинга цен криптовалют. Бот предоставляет актуальные данные о ценах, позволяет добавлять криптовалюты в избранное, а также имеет админ-панель для управления пользователями и рассылкой сообщений.

## Особенности

- 💰 Мониторинг цен криптовалют
- 🔝 Популярные криптовалюты
- ⭐ Добавление криптовалют в избранное
- 📊 Статистика использования бота
- 👨‍💻 Админ-панель для управления пользователями и рассылкой сообщений
- 🔄 Обновление данных каждые 5 минут

## 🛠 Технологический стек

- **Backend**: Python
- **Frontend**: Telegram Bot API
- **Database**: PostgreSQL
- **Libraries**: `pyTelegramBotAPI`, `requests`, `psycopg2-binary`, `cachetools`

## Установка

1. **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/sparrow1110/telegram-crypto-tracker.git
    cd telegram-crypto-tracker
    ```

2. **Переключитесь на ветку `master`:**

    **Примечание:** Ветка `master` не является веткой по умолчанию. Выполните следующие команды для переключения на ветку `master`:

    ```bash
    git fetch --all
    git checkout master
    ```

3. **Создайте виртуальное окружение и активируйте его:**

    ```bash
    python -m venv venv
    source venv/bin/activate  # Linux/MacOS
    venv\Scripts\activate     # Windows
    ```

4. **Установите зависимости:**

    ```bash
    pip install -r requirements.txt
    ```

5. **Создайте файл `config.py` в корневой директории проекта и добавьте туда следующие настройки:**

   ```python
   TOKEN = 'ВАШ_TELEGRAM_BOT_TOKEN'
   ADMIN_IDS = []  # Список ID админов
   DB_CONFIG = {
       'dbname': 'ИМЯ_БАЗЫ_ДАННЫХ',
       'user': 'ИМЯ_ПОЛЬЗОВАТЕЛЯ',
       'password': 'ВАШ_ПАРОЛЬ',
       'host': 'localhost',
       'port': '5432'
   }
   DATA_FILE = 'crypto_prices.json'
   ```

6. **Запустите бота:**

    ```bash
    python main.py
    ```

## Использование

1. **Запуск бота:**
    - Запустите бота, выполнив команду `python main.py`.
    - Бот будет доступен в Telegram по вашему токену.

2. **Основные команды:**
    - `/start`: Начало работы с ботом.
    - `/prices`: Получение актуальных цен популярных криптовалют.
    - `/favorites`: Показать избранные криптовалюты.
    - `/help`: Справка по всем командам.

3. **Админ-панель:**
    - `/admin`: Доступ к админ-панели (только для администраторов).
    - В админ-панели доступны функции рассылки сообщений, блокировки/разблокировки пользователей, получения статистики бота и популярных криптовалют.

## Ветки

- **master**: Ветка с монолитной архитектурой (текущая ветка).
- **microservice-architecture**: Ветка с микросервисной архитектурой.

## Структура проекта

- `main.py`: Основной файл бота, содержащий логику работы.
- `admin_panel.py`: Класс для управления админ-панелью.
- `config.py`: Конфигурационный файл с настройками (должен быть добавлен в `.gitignore`).
- `db_handler.py`: Класс для взаимодействия с базой данных PostgreSQL.
- `requirements.txt`: Файл с зависимостями проекта.
